# Security policy

Please report a vulnerability in Carrick by email to security@carrick.tools, not in a public issue or pull request.

This covers the scanner, the GitHub Action and the `carrick` npm package in this repository, and the hosted service behind `api.carrick.tools` and `app.carrick.tools`.

A useful report says what is affected, how to reproduce it, and what an attacker could do with it. We reply to every report and keep you informed until it is fixed.

Fixes ship in the latest release, so please check a report against the newest version on npm (`npm view carrick version`).
